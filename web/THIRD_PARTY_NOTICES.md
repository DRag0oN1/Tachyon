# Tachyon frontend dependency provenance

Generated by `npm run licenses` from the exact npm lockfile and installed packages.
Dependencies remain separate from all CAD source rights. No third-party CAD, fonts,
icons, images or application source have been copied into the frontend. Original
UI icons and assistant glyphs were authored for Tachyon.

Full available installed copyright/license texts are retained in
[public/THIRD_PARTY_NOTICES.txt](public/THIRD_PARTY_NOTICES.txt), which Vite also
includes in the built distribution. Uninstalled optional platform binaries appear
in the lockfile provenance table but are not distributed. Registry tarball identity
and integrity are recorded in `package-lock.json`.

SHA-256 HTTP/LAN fallback uses the MIT-licensed [noble-hashes upstream API](https://github.com/paulmillr/noble-hashes#usage). React 19 and Fiber 9 compatibility follows the [official R3F documentation](https://r3f.docs.pmnd.rs/getting-started/introduction).
